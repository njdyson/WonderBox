Avatar pictures from Microsoft's Fluent Emoji (3D style), MIT licence:
https://github.com/microsoft/fluentui-emoji

Named by the emoji's code point, so `1f98a.webp` is 🦊. The phone app has a copy in
`server/pb_public/avatars/`; keep the two sets the same.

The TV also draws its game and home-page icons from here (🧩 🔢 🔤 🕒 🎈 🃏 ❓ 🎮 📺 🎵 🤸
📷), so they look the same on old Fire TVs. Those aren't avatars, so the phone app doesn't
need them.
